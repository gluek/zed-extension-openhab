# Openhab-Zed

## Introduction
This project implements the vscode-extension for openhab for the Zed Editor.
The reference can be found here: https://github.com/openhab/openhab-vscode

## Behaviour
- Delegate small and simple jobs to a sub-agent. Use *Qwen3.5-9B*. If you cannot use this model, do not delegate the task and do it yourself.
- Before starting anything formulate a small step-by-step list. Show the progress by ticking off items on the list.
